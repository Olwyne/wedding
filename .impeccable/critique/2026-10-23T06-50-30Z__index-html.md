## Overall Impression

Strong ceremonial opening, let down by a hard keyboard wall at the very first interaction and a now-confirmed severe contrast bug in the teaser; RSVP protects against bad data but not against guest fatigue/abandonment.

## Priority Issues

**[P0] Envelope entry ritual not keyboard-operable** — plain div, click-only, no tabindex/role/keydown. Hard wall before any content. Fix: role="button", tabindex="0", Enter/Space handler. /impeccable harden

**[P0] Near-invisible text in teaser (1.1:1 contrast)** — #6e241c on #661819, below WCAG minimum even for large text. Fix: identify the exact element and retint to parchment/cream/gold. /impeccable harden

**[P1] No ARIA state on custom toggle/event controls** — state only in CSS class; #rsvp-error has no aria-live. Fix: aria-pressed on toggles/events, aria-live on error/thanks regions. /impeccable harden

**[P1] RSVP "yes" branch (10-15 fields) has no chunking or progress** — fails 4/8 cognitive-load checklist items; invite cap scrolls out of view before the fields it constrains. Fix: visual sub-sections, repeat the cap near named-guest fields. /impeccable clarify

**[P2] Message required even on decline** — unnecessary friction at an already-delicate moment. Fix: required only when presence==='yes'. /impeccable clarify

**[P2] No autocomplete attributes; generic submit error** — retyping on mobile; unclear whether already-uploaded photos survive a retry. Fix: autocomplete="name"/"email"/"tel"; differentiate failure messaging. /impeccable polish
